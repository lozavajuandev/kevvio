# Public rental listing
Mode: Persuade. A prospective tenant arriving from a link must understand the property, price and next action without an account.

THESIS: Let the real property lead, then make the next conversation easy.
OWN-WORLD: The studio's Manrope, blue, white and navy system with vivid orange primary actions and brand details. A large real photo precedes details; the price and contact panel remain easy to find. No promotional claims or invented amenities.
STORY: Browse selected photos, understand the location, rooms and cost, then contact the manager by WhatsApp or email. Expired, disabled and invalid links show one clear unavailable state.
FIRST VIEWPORT: A restrained brand line, large image gallery, property title and rental price. Desktop separates reading from a sticky contact column; mobile stacks the same content with full-width contact actions. An image dialog permits closer inspection.
FORM: Published snapshots contain only the selected fields and general property photos. Exact address is opt-in. No internal inventory, documents, tenants, payments or acquisition information is available publicly. A token is an unlisted link, not a recipient identity check. The user has chosen local preparation; internet sharing awaits hosting.
FINISH: Review the actual dynamic page at desktop and mobile widths plus unavailable state. No shipping authored rasters; photographs remain user uploads.
